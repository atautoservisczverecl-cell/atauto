# A.T. Autoservis – web

Astro 5 (statický web) + Vercel funkce v `api/` + administrace na `/administrace/` (Supabase).

- `npm install`, `npm run dev`, `npm run build`
- Databáze: `supabase/schema.sql`
- Proměnné prostředí (Vercel): RESEND_API_KEY, INQUIRY_TO, INQUIRY_FROM, PUBLIC_SUPABASE_URL, PUBLIC_SUPABASE_ANON_KEY, DEPLOY_HOOK_URL
